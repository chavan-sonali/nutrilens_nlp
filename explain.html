🥗 NutriLens: System Architecture & Technical Explanation

An NLP-Powered Food Nutrition Search, Classification & Nutrient Ranking Engine

📖 1. Project Overview (In Short)

NutriLens is a natural language processing system that allows users to ask food and dietary questions in plain English (e.g. "high protein vegetarian food for weight loss", "what can a diabetic person eat for breakfast?", or "citrus fruits rich in vitamin C") and receive ranked, nutrition-aware food recommendations backed by exact explanations.

The Core Problem Solved: Nutrition databases store static numbers (grams of protein, calories, fiber), but people think and speak in natural language. Keyword-based matching fails when queries use paraphrases like "good for gut health" or comparative constraints like "high protein". NutriLens resolves this by combining Lexical TF-IDF, Dense Semantic Embeddings, and Rule-based NLU (Quantile Extraction).

Dataset: An authoritative corpus of 100 foods × 14 attributes across 12 balanced food groups (Vegetable, Fruit, Grain, Pulse, Dairy, Nut & Seed, Seafood, Spice, Beverage, Meat, Egg, Herb) covering macronutrients, micronutrients, serving sizes, long descriptions, health benefits, and audience tags.

🧠 2. NLP & Machine Learning Algorithms Used

A. Text Preprocessing & Lemmatization

  • Tokenization: Regex word boundary segmentation with punctuation stripping.
  • Stop-word Removal: Filtered using the spaCy en_core_web_sm stop list (removes noise like the, is, also, delivers).
  • Morphological Lemmatization: Reduces inflected words to dictionary lemmas (e.g., apples → apple, supports → support, diabetics → diabetic).

B. TF-IDF Vectorizer & Cosine Similarity

  • N-gram Range: Unigrams + Bigrams (1, 2) to capture critical phrases like vitamin c, weight loss, blood sugar.
  • Sublinear TF: Applies 1 + ln(tf) scaling to prevent frequent terms from dominating documents.
  • Smooth IDF: Inverse Document Frequency formula: ln((1 + N) / (1 + df)) + 1.0.
  • Cosine Similarity: Normalized dot product measuring exact keyword overlap.

C. Dense Semantic Embeddings (MiniLM-style)

  • Conceptual Vector Space: 16-D physiological latent space embedding (Digestion, Muscle Hypertrophy, Glycemic Regulation, Cardiovascular, etc.).
  • Paraphrase Match: Allows semantic queries like "good for gut health" to match foods supporting microbiome, digestion, and fiber even when the exact words are absent.

D. Rule-based NLU & Quantile Extraction

  • Dynamic Percentiles: Computes 25th (Q25) and 75th (Q75) dataset quantiles in real time: protein_g ≥ Q75 (8.1g), calories_kcal ≤ Q25 (45.0 kcal), etc.
  • Entity Regex Matcher: Extracts 10 target audiences (Diabetic Patients, Weight Loss, Athletes), 18 micronutrients, and 12 food categories.

E. Hybrid Retrieval & Re-ranking Formula

Final_Score = α · TF_IDF_Score + (1 - α) · Semantic_Score + 0.50 · NLU_Filter_Boost

The parameter α (default 0.40) balances exact lexical fidelity with dense conceptual similarity. Foods that meet extracted structured constraints receive a +0.50 boost.

F. Text Classification & Label Leakage Experiment

Predicts one of the 12 food categories from description text using a Multinomial Bayes / Softmax classifier with Laplace smoothing (α = 0.8).

  • Baseline Mode: Trained on full descriptions (contains explicit words like "fruit", "vegetable") → ~90%+ accuracy.
  • Leak-Free Mode: Category words are stripped prior to training. The model must classify based strictly on functional nutrients, textures, and culinary traits → tests genuine semantic generalization.

G. Evaluation Metrics

Metric Formula / Definition Role in NutriLens
Precision@5 hits_in_top_5 / 5 Measures top-5 recommendation accuracy
Recall@10 hits_in_top_10 / total_relevant Measures coverage of relevant foods in dataset
MRR 1 / rank_of_first_relevant_item Measures how quickly the user finds a relevant food
nDCG@5 Normalized Discounted Cumulative Gain Measures position-weighted ranking quality

💻 3. Technology Stack: Frontend & Backend

🎨 Frontend Stack

Built for responsive multi-device presentation with modern micro-interactions:

  • React 19 & TypeScript: Component-driven SPA architecture with strong type safety for all 14 food attributes.
  • Tailwind CSS v4: Custom styling with an 8xl container (max-w-8xl) adapting seamlessly to mobile, tablet, and wide desktop screens.
  • Motion (Framer Motion v12): Physics-based spring animations for the active sliding navbar pill (layoutId="activeTabPill"), staggered card fade-ins, and animated nutrient density bars.
  • Lucide React Icons: Clean modern iconography for all categories, nutrients, and CLI controls.
  • Typography: Google Fonts — Poppins (headings), Inter (body), and JetBrains Mono (monospace numbers & CLI output).

🐍 Backend & NLP Stack

Dual-runtime architecture tailored for academic NLP grading:

  • Python 3.10+ (Core NLP Deliverable):
    • main.py: Standalone CLI engine runnable via python3 main.py --query ...
    • python_src/preprocess.py: Text cleaning, spaCy stopword lists, and morphological lemmatizer.
    • python_src/search.py: TF-IDF and dense semantic vector computation.
    • python_src/nlu.py: Quantile calculations and regex pattern matchers.
    • python_src/classify.py: Multiclass classifier and leakage experiment.
    • python_src/evaluate.py: 20-query automated ground-truth benchmark suite.
  • Streamlit (app.py): Native Python dashboard for local execution via streamlit run app.py.
  • Jupyter Notebooks (notebooks/): 4 notebooks covering EDA, preprocessing & search, classification, and evaluation.
  • Vite & Express Web Server: Serves the interactive web applet on port 3000 in AI Studio.

🚀 4. How to Run

A. Run via Python CLI:

# 1. Search with natural language query
python3 main.py --query "high protein vegetarian food for weight loss"

# 2. List foods ranked by nutrient (e.g. protein high to low)
python3 main.py --rank protein_g --direction desc

# 3. Run the 20-query benchmark evaluation
python3 main.py --evaluate

# 4. Classify a food description
python3 main.py --classify "Crisp sweet tree apple harvest with high pectin"

B. Run the Python Streamlit App:

pip install -r requirements.txt
streamlit run app.py
